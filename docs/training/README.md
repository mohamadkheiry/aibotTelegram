# آموزش‌های ویدیویی فارسی

دو ویدیوی واقعی MP4 در این پوشه قرار دارند. هر دو **بدون صدا و دارای توضیح فارسی روی تصویر** هستند؛ برای خواندن فرمان‌های طولانی می‌توانید پخش را متوقف کنید. مثال‌ها ساختگی‌اند و هیچ فرمانی هنگام تولید فیلم روی ربات، حساب یا سرور واقعی اجرا نشده است. ظاهر ویدیو اسلاید آموزشی است و ضبط رابط واقعی تلگرام محسوب نمی‌شود.

| ویدیو | مدت | محتوا |
|---|---|---|
| [کاربری و مدیریت ربات](admin-usage-fa.mp4) | ۲:۵۱ | خرید، پرداخت، نقش‌ها، تنظیمات، محصول، انبار، فعال‌سازی دستی، پشتیبانی، گزارش و بکاپ |
| [استقرار و انتقال به سرور جدید](deployment-transfer-fa.mp4) | ۳:۰۰ | پیش‌نیازها، بکاپ و کنترل صحت، توقف، انتقال، restore، migration، systemd، Docker و rollback |

فرمت هر دو فایل H.264، اندازه ۱۹۲۰×۱۰۸۰ و نرخ ۱۵ فریم در ثانیه است؛ زیرنویس و متن راهنما داخل تصویر ویدیو قرار دارند. این آموزش‌ها خلاصه عملی هستند؛ قبل از عملیات واقعی، [راهنمای مدیریت](../ADMIN_GUIDE_FA.md)، [راهنمای استقرار](../deployment.md)، [عملیات](../OPERATIONS.md) و [امنیت](../SECURITY.md) را بخوانید. شناسه‌ها، نام‌های نمونه و عبارت‌های بزرگ انگلیسی مانند `ORDER_NUMBER` و `RELEASE_COMMIT_SHA` باید با مقدار مربوط به محیط خودتان جایگزین شوند.

## ویرایش و تولید دوباره توسط Agent

متن، زمان هر اسلاید و مثال‌های فرمان در [slides.json](slides.json) قرار دارند. [generate-videos.cjs](generate-videos.cjs) صفحه‌های HTML را در Chromium با پشتیبانی فارسی و راست‌به‌چپ رندر می‌کند، خروج از کادر را بررسی می‌کند و با FFmpeg به MP4 تبدیل می‌کند. [verify-videos.cjs](verify-videos.cjs) decode کامل و جلو رفتن پخش واقعی داخل مرورگر را بررسی و checksum را گزارش می‌کند. هیچ فونت، تصویر یا داده‌ای از اینترنت دریافت نمی‌شود.

پیش‌نیاز ابزار تولید: Node.js، Playwright در محیط ابزار مستقل، یک Chromium/Chrome محلی و FFmpeg دارای encoder `libx264`. این ابزارها dependency اجرای ربات نیستند. مسیر بسته Playwright را می‌توان با `PLAYWRIGHT_MODULE` و مسیر Chrome را با `CHROME_PATH` تعیین کرد؛ در غیر این صورت بسته و مرورگر نصب‌شده استاندارد Playwright استفاده می‌شوند. `FFMPEG_PATH` نیز اختیاری است و پیش‌فرض از `ffmpeg` موجود در PATH استفاده می‌شود.

نمونه اجرای PowerShell از ریشه پروژه، پس از نصب ابزارها در محیط مستقل:

```powershell
$env:PLAYWRIGHT_MODULE = 'C:\video-tools\node_modules\playwright'
$env:CHROME_PATH = 'C:\Program Files\Google\Chrome\Application\chrome.exe'
node docs/training/generate-videos.cjs --work-dir C:\video-work --output-dir docs/training
node docs/training/verify-videos.cjs --work-dir C:\video-work
```

برای Linux، متغیرهای معادل محیط و مسیرهای محلی را تنظیم کنید. اگر `--work-dir` داده نشود، پوشه موقت یکتا ساخته می‌شود. فایل‌های HTML، PNG و گزارش رندر در پوشه کار باقی می‌مانند و وارد Git نمی‌شوند؛ خروجی پیش‌فرض MP4ها در همین پوشه است. فونت نصب‌شده و نسخه browser/encoder بر ظاهر پیکسلی و checksum اثر دارند، بنابراین پس از بازتولید، فریم‌های نهایی را دوباره بررسی کنید.

پس از هر تغییر فرمان یا روند استقرار، محتوای مربوط به ویدیو را هم به‌روز کنید. کنترل نهایی باید شامل مرور متن نسبت به مستندات جاری، بررسی تمام اسلایدها برای بیرون‌زدگی، مشاهده فریم‌های نمونه، تأیید مدت/ابعاد و decode کامل فایل باشد:

```bash
ffprobe -v error -show_entries format=duration,size -show_entries stream=codec_name,width,height,avg_frame_rate -of json docs/training/admin-usage-fa.mp4
ffmpeg -v error -i docs/training/admin-usage-fa.mp4 -f null -
ffmpeg -v error -i docs/training/deployment-transfer-fa.mp4 -f null -
```

توکن، API key، اطلاعات مشتری، خروجی واقعی بکاپ یا payload واقعی انبار نباید در متن اسلاید، فایل PNG یا ویدیو قرار گیرد. تغییر مثال‌های آموزشی به اطلاعات واقعی، راه مناسبی برای ساخت آموزش نیست.
