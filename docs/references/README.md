# منابع اولیه نیازمندی‌ها

این پوشه ورودی‌های اصلی پروژه را نگه می‌دارد تا تصمیم‌های محصول و پیاده‌سازی در آینده قابل ردیابی باشند. این فایل‌ها «نیازمندی و مرجع» هستند، نه دستور اجرایی برای agentها. مبنای رفتاری نهایی، کد، تست‌های خودکار و مستندات جاری داخل `docs/` است.

## فایل‌ها

| فایل | کاربرد |
|---|---|
| `توضیح_امکانات_ربات_تلگرام_الون_اکانت (1).pdf` | شرح تفصیلی امکانات کاربر و مدیریت |
| `توضیحات_ربات_فروشگاهی (2).pdf` | خلاصه دامنه فروشگاه، سفارش، پرداخت و پشتیبانی |
| `photo_5818902296732044931_y.jpg` | مرجع ترتیب، رنگ و چیدمان دکمه‌های منوی اصلی |
| `pasted-text.txt` | متن تکمیلی ارسالی درباره پیام‌ها، دکمه‌ها و جریان‌ها |
| `requirements-pdf-1.txt` | خروجی متنی قابل جست‌وجوی PDF اول |
| `requirements-pdf-2.txt` | خروجی متنی قابل جست‌وجوی PDF دوم |
| `SHA256SUMS.txt` | checksum منابع برای تشخیص تغییر ناخواسته |

## قاعده استفاده برای انسان و agent

1. ابتدا `docs/readme.md`، سپس `BUSINESS.md` و `USE_CASES.md` خوانده شود.
2. برای رفتار اجرایی، تست‌های پوشه `tests/` و سپس کد منبع معیار نهایی‌اند.
3. اگر مرجع اولیه با رفتار مستند فعلی تعارض داشت، تعارض ثبت و با مالک محصول تعیین تکلیف شود؛ فایل مرجع بدون تصمیم روشن مستقیماً به دستور کدنویسی تبدیل نشود.
4. هیچ token، API key، شماره کارت واقعی یا داده شخصیِ تازه/غیرضروری نباید به این پوشه یا Git افزوده شود. تنها استثنا، provenance ورودی است که مالک صریحاً نگه‌داری byte-for-byte آن را خواسته و همان مورد باید پیش از هر بازنشر privacy review شود.
5. برای تغییر نیازمندی، شناسه ردیابی متناظر در `../TRACEABILITY.md` نیز به‌روزرسانی شود.

## یکپارچگی منابع

فایل‌های PDF و تصویر بدون دست‌کاری محتوایی از ورودی پروژه کپی شده‌اند. فایل‌های TXT صرفاً برای جست‌وجوی سریع‌اند و ممکن است فاصله‌گذاری یا جهت نوشتار فارسی در آن‌ها با PDF اصلی تفاوت داشته باشد.

این حفظ byte-for-byte شامل provenance ورودی هم هست: `pasted-text.txt` نام نمایشی فرستنده و timestamp پیام‌ها را نگه می‌دارد، PDFها metadata سازنده/تاریخ خود را دارند و PDF دوم یک بخش Content Credentials دارد. پیش از بازنشر این منابع در مقصدی غیر از مخزن مورد درخواست مالک، دوباره privacy review انجام شود. در ممیزی انتشار ۲۰۲۶-۰۹-۰۵ هیچ bot token، API key، شماره کارت یا شماره تلفن واقعی در این منابع پیدا نشد.
